# GUI 构建记录 — 2026-11-06

## 做了什么

- 新增 `gui.py`（tkinter，Python 标准库，零新增依赖）：
  - 文件选择器（输入 PDF）+ 输出路径选择（默认与 PDF 同目录、同名 `.csv`）
  - 可选年份输入框（只影响 `MM-DD` 类无年份日期；留空自动推断；非法输入弹人话提示）
  - “开始转换”按钮：转换在后台线程跑，界面不卡死；状态行实时显示进度与结果
  - 结果区显示：提取笔数、输出路径、疑似漏提行数（启发式统计，见下）、核对提醒
  - 错误全部用人话显示（文件不存在、非 PDF、读不到/损坏/加密、扫描件不支持）
  - 界面底部写明诚实范围：仅数字 PDF、不含 OCR、无安装程序、无自动更新
- 后端与界面分离：`run_conversion(pdf, csv, year)` 是可独立测试的纯函数，
  返回 `ConversionResult(ok/error/rows/output/skipped)`，永不抛异常；
  GUI 只调用它。`default_output_path()` 同样可独立测试。
- 新增 `test_gui.py`（pytest，不需要显示器）。
- `run_tests.sh` 现跑 `test_converter.py test_gui.py`（一条命令全量）。
- `README.md`：新增“图形界面”小节；“仍待做”里去掉“图形界面”，
  安装程序、自动更新仍在待做清单里；文件清单补了 `gui.py` / `test_gui.py`。

## 已知限制（诚实口径）

- **仅数字 PDF**：扫描件 / 图片型 PDF 无法转换（无 OCR），失败提示会明说。
- **疑似漏提行数是启发式统计**：含日期的文本行数 − 已提取行数；表头日期、
  汇总行也可能被计入，只作“请打开 CSV 核对”的提示，不是精确漏提计数。
- **未做真实银行 PDF 验证**：与转换器本体一致，只在合成 fixture 上验证。
- **界面未在有显示器的机器上点检过**（见测试结果段）。
